NVDA Dark Mode

Makes NVDA's own interface dark: the NVDA menu, the Settings dialog, the Add-on Store, message boxes and every other NVDA window.

Settings

Open NVDA's Settings dialog and choose the Dark Mode category. The one setting is when dark mode applies:

  • Follow Windows setting (default): dark when Windows is set to dark mode for apps, light otherwise.
  • Always on
  • Off

Dark mode switches itself off while a Windows High Contrast theme is active, so it never fights your contrast theme.

Toggle command

A command called Toggles dark mode for NVDA's windows and menus is available in NVDA's Input Gestures dialog, under the Dark Mode category. It has no key assigned by default.

How it works, and its limits

NVDA's interface is drawn by a toolkit (wxPython) that has no dark mode of its own, so this add-on asks Windows directly, using the same unofficial switches File Explorer and other apps use. Most of the interface goes dark. A few pieces Windows draws itself may stay light, for example slider tracks. When NVDA gains built-in dark mode, this add-on can be retired.
