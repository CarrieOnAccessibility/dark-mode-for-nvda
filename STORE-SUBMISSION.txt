STEP 1 - PUBLISH THE RELEASE ON GITHUB (about two minutes)
----------------------------------------------------------
The tag v0.9.2 is already on GitHub. Turning it into a release gives the store a
permanent download address that lives next to the source code.

   1. Open https://github.com/CarrieOnAccessibility/dark-mode-for-nvda/releases/new?tag=v0.9.2
      (sign in as CarrieOnAccessibility if asked).
   2. Release title:  Dark Mode 0.9.2 (beta)
   3. Description (paste):
      First public beta. Dark mode for NVDA's own windows, dialogs, menus and
      help pages. Needs NVDA 2026.1 or later; black title bars and the grey
      window outline need Windows 11. See the change log on
      https://apps.carrieonaccessibility.com/apps/dark-mode/
   4. Attach the file: drag darkMode-0.9.2.nvda-addon from the dist folder
      (path above) into the "Attach binaries" box, and wait for the upload to
      finish.
   5. Tick "Set as a pre-release" (it is a beta). Leave "Set as the latest
      release" unticked. Press "Publish release".

   The file's address will then be exactly:
   https://github.com/CarrieOnAccessibility/dark-mode-for-nvda/releases/download/v0.9.2/darkMode-0.9.2.nvda-addon

   If you would rather skip this step, the website address above works for the
   form too - it is the same file. GitHub is the tidier home for it.

STEP 3 - WAIT, AND WATCH THE ISSUE
----------------------------------
   - Within minutes, a robot downloads the file, checks it, scans it with
     VirusTotal, and opens a pull request. If a check fails, it writes a comment
     on your issue saying what; send that to Claude and resubmit after the fix.
   - Because this is the first submission of a new add-on, a person at NV Access
     has to approve you as its publisher. That can take up to two weeks. There is
     nothing to do while you wait; you are the maintainer, so no extra proof is
     needed.
   - When approved and the checks pass, the pull request merges itself and Dark
     Mode appears in the Add-on Store's beta channel. (Users see beta add-ons
     only if they have chosen to show them in the store's settings.)
   - Every later version is the same form again, with the new download address.
     Updates from an approved publisher do not need the two-week wait.
