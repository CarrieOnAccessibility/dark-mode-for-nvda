STEP 3 - PUBLISH THE RELEASE ON GITHUB  (you, about two minutes, in the browser)
-------------------------------------------------------------------------------
This gives the store a permanent download address next to the source code.
   1. Open https://github.com/CarrieOnAccessibility/dark-mode-for-nvda/releases/new?tag=vX.Y.Z
      (Claude gives you the exact link with the version filled in; sign in as
      CarrieOnAccessibility if asked).
   2. Release title:  Dark Mode X.Y.Z (beta)
   3. Description (paste):
      First public beta. Dark mode for NVDA's own windows, dialogs, menus and help pages,
      with optional black backgrounds and thicker focus outlines. Needs NVDA 2026.1 or
      later; black title bars and the grey window outline need Windows 11. Change log:
      https://apps.carrieonaccessibility.com/apps/dark-mode/
   4. Drag the .nvda-addon file (path in step 2) into the "Attach binaries" box and wait
      for the upload to finish.
   5. Tick "Set as a pre-release" (it is a beta). Leave "Set as the latest release"
      unticked. Press "Publish release".
   The file's address will then be:
   https://github.com/CarrieOnAccessibility/dark-mode-for-nvda/releases/download/vX.Y.Z/darkMode-X.Y.Z.nvda-addon

   Shortcut: if you would rather skip this step, the website address from step 2 works
   for the form too - it is the same file. GitHub is just the tidier home for it.

STEP 5 - WAIT, AND WATCH THE ISSUE  (nothing to do, just know what happens)
--------------------------------------------------------------------------
   - Within minutes a robot downloads the file, checks it and scans it with VirusTotal,
     then opens a pull request. If a check fails it comments on your issue saying what;
     send that comment to Claude, and resubmit after the fix.
   - First submission of a new add-on: a person at NV Access approves you as its
     publisher. Up to two weeks. Nothing to do while you wait; you are the maintainer,
     so no extra proof is needed.
   - Once approved and green, the pull request merges itself and Dark Mode appears in
     the Add-on Store's beta channel. (People see beta add-ons only if they have chosen
     to show them in the store's settings.)
   - Every later version is the same form again with the new address, and updates from
     an approved publisher do not need the two-week wait.
